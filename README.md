# Site Aide Missionnaire

Site internet de l’association Aide Missionnaire, qui soutient l’éducation, la santé et l’aide sociale à Mandoto (Madagascar).

Le site est en HTML, CSS et JavaScript. Aucun outil de compilation n’est nécessaire.

## Fichiers

| Fichier | Page |
| --- | --- |
| `index.html` | Accueil |
| `parrainage.html` | Parrainage (formulaire) |
| `don.html` | Dons (HelloAsso) |
| `galerie.html` | Galerie photos |
| `association.html` | L’association |
| `contact.html` | Contact |
| `mentions-legales.html` | Mentions légales |
| `politique-confidentialite.html` | Politique de confidentialité |
| `styles.css` | Apparence du site |
| `script.js` | Menu mobile, formulaires, totaux, galerie |
| `images/` | Logo, favicon et photos |

## Dossier images

- `logo.png` et `favicon.png` : identité visuelle
- `accueil.jpg` : grande photo de la page d’accueil
- `galerie-01.jpg` à `galerie-20.jpg` : photos de la galerie
- `don-nourriture.png`, `don-soins.png`, `don-projets.png` : page Don
- `rehab-avant.png` et `rehab-apres.png` : comparateur avant / après

Pour changer une photo, remplacez le fichier dans `images/` en gardant le même nom.

## Modifier le site

1. Ouvrez le dossier du projet.
2. Double-cliquez sur `index.html` pour l’afficher dans le navigateur.
3. Modifiez le texte dans les fichiers `.html`.
4. Les couleurs et mises en page se règlent dans `styles.css`.

Les formulaires de contact et de parrainage envoient un e-mail à `aidemissionnaire@gmail.com`.
Les dons en ligne passent par HelloAsso.
